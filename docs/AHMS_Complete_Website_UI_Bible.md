# AHMS Complete Website UI Bible (Starter Edition)

> Premium + Classic + Ayurvedic Website Design Bible Based on the
> provided SOW for the Ayurvedic Hospital Management System.

------------------------------------------------------------------------

# Design Vision

Create a website that immediately communicates:

-   Trust
-   Healing
-   Heritage
-   Modern Healthcare
-   Ayurveda
-   Premium Institution
-   Academic Excellence

The visual language should feel like a blend of Apple, Forest
Essentials, Kama Ayurveda, Apollo Hospitals and Awwwards---not a generic
medical template.

------------------------------------------------------------------------

# Brand Identity

Mood: - Calm - Luxurious - Clean - Timeless - Spiritual - Scientific

Never use: - Bright neon colors - Generic Bootstrap cards - Cluttered
layouts - Excessive gradients

# Typography

Headings: Poppins

Body: Inter

------------------------------------------------------------------------

# Imagery

Use: - Medicinal herbs - Neem - Tulsi - Ashwagandha - Doctors with
patients - Panchakarma - Hospital campus - Nature - Wooden textures -
Copper utensils - Soft sunlight

Avoid stock-looking images.

------------------------------------------------------------------------

# Global Motion System

Use: - Framer Motion - GSAP - Lenis

Animations: - Page transitions - Blur reveal - Fade up - Character text
reveal - Image parallax - Floating leaves - Mouse glow - Glass hover -
Magnetic buttons - Ripple click - Counter animations - Skeleton
loading - Animated tabs - Sticky storytelling - Scroll progress
indicator

Animation duration: 0.4--0.8s

Always use smooth easing.

------------------------------------------------------------------------

# Animated Navbar

Requirements:

Transparent at top.

After scroll: - Glass background - Blur - Rounded bottom - Shrink
height - Active link indicator - Animated underline - Mega menu -
Emergency CTA - Book Appointment CTA - Fullscreen animated mobile
drawer - Search overlay - Dark mode - Notification icon - Floating
profile button
